## 1. 这是什么工具

Squalr 是一款用 Rust 编写的高性能**内存扫描与动态分析（逆向工程）工具**。它的核心能力是：

- 以极高速度扫描目标进程的内存（多线程 + SIMD 加速），几 GB 内存通常几秒内扫完。
- 支持整数、浮点、大端、数组、字符串、指令序列、十六进制通配符等多种扫描方式。
- 在一次扫描的基础上做"下次扫描"逐步缩小范围（等于 / 未变化 / 增加 / 减少 / 增加 x 等条件）。
- 查看内存原始字节、反汇编代码、修改指令、设置断点、跟踪谁读写了某个地址。
- 用**指针扫描**找到稳定的多级指针链（重启程序后仍然有效的地址）。
- 用**项目系统**保存扫描结果、地址、指针链、符号与结构布局。

本版本已经完成**界面汉化**，并内置了中文字体自动回退，无需额外配置即可显示中文。

> 与 Cheat Engine 的差别：Squalr 更偏"动态分析工具"，界面和术语更工程化；本教程会尽量用通俗语言说明。

## 2. 运行前准备

### 2.1 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（64 位） |
| 权限 | **建议以管理员身份运行**（否则无法打开部分进程 / 读写受保护内存） |
| 内存 | 建议 8 GB 以上（扫描大进程时会占用较多内存） |
| 磁盘 | 约 100 MB（含日志与项目文件） |
| CPU | 支持 SSE / AVX / AVX-512 可获得最佳扫描速度 |

### 2.2 放置位置（重要）

程序会在**自身所在目录**写入配置文件：

- `docking_settings.json`（窗口布局）
- `scan_settings.json`（扫描与内存查询设置）
- `project_settings.json`（项目根目录设置）

因此请**不要**把程序放进 `C:\Program Files\` 这类需要管理员权限才能写入的目录，否则设置无法保存。
推荐放在例如 `D:\Tools\Squalr\` 或桌面文件夹中。

### 2.3 启动

1. 右键 `squalr.exe` → **以管理员身份运行**。
2. 首次启动后会自动创建上述配置文件。
3. 若需要中文界面之外的字体（例如想换更漂亮的字体），可在 `squalr.exe` 同级目录新建 `fonts` 文件夹，放入任意中文字体（如 `NotoSansSC-VF.ttf`、`msyh.ttc`、`simhei.ttf`），程序会优先使用它。

> 说明：程序默认会依次尝试系统中的 `C:\Windows\Fonts` 等目录里的中文字体（微软雅黑、黑体、等线、思源黑体等），正常情况下无需任何操作。

## 4. 快速上手：修改一个数值

以"修改某个游戏里的金币数量"为例（任何可读写的进程都适用）。

### 步骤 1：附加目标进程

1. 让目标程序处于运行状态。
2. 在 Squalr 顶部 `选择进程...` 中选择它。
3. 状态正常时，进程名会显示在下拉框中。

### 步骤 2：确认数据类型

在**扫描器**窗口第一行选择数据类型。常用：

| 数据类型 | 说明 |
| --- | --- |
| `i32` / `u32` | 32 位整数，最常见（金币、血量、等级） |
| `i64` / `u64` | 64 位整数 |
| `f32` / `f64` | 浮点数（坐标、百分比、速度） |
| `String (UTF-8)` | 字符串 |
| `i_x64` | x86-64 指令序列（用于汇编扫描） |
| `u16be` / `i32be` 等带 `be` 后缀 | 大端序 |

> 不确定类型时，先从 `i32` 开始；如果扫不到，再试 `f32`、`i64`。

### 步骤 3：首次扫描

1. 比较条件保持 **等于**。
2. 在数值框中输入当前数值（例如 `1000`）。
3. 点击右侧 **▶（开始扫描）** 按钮。

扫描完成后，结果会显示在**扫描器下方的结果列表**中，列依次为：

- **地址** —— 内存地址（十六进制）
- **数值** —— 当前读到的值
- **上一次数值** —— 上一次扫描时记录的值

### 步骤 4：让数值发生变化

回到游戏里，让这个数值**发生变化**（例如花掉一部分金币，或再赚一点）。

### 步骤 5：下次扫描（缩小范围）

1. 把比较条件改成 **未变化** / **已变化** / **增大** / **减小** / **增加 x** / **减少 x**。
2. 若使用"增加 x / 减少 x"，需要在数值框里填入变化量。
3. 再次点击 **▶**。

> 小技巧：使用"增加 x / 减少 x"之前，先点一次 **采集数值**（图标：小方块集合）记录当前值，这样差异比较才准确。

重复步骤 4–5，直到结果只剩几条。

### 步骤 6：验证并修改

1. 双击某条结果可将其**打开到详情查看器**（也可右键 → 在内存查看器中打开）。
2. 在**详情查看器**里修改数值，按回车提交。
3. 回到游戏确认数值已改变。若没变，说明这条不是真正的目标地址，换另一条继续验证。

### 步骤 7：冻结数值（可选）

在结果列表中勾选某条结果前的**冻结**复选框，程序会每隔一段时间把该地址写回指定值，防止游戏把它改回去。冻结间隔可在 **设置 → 扫描 → 内存读取间隔 → 冻结间隔（毫秒）** 中调整。

### 步骤 8：保存成果

- 右键结果 → **添加到项目**，即可把该地址保存到项目里，下次直接使用。
- 或者继续做[指针扫描](#9-指针扫描)，得到重启后依然有效的地址。

## 5. 扫描模式详解

扫描器第一行的**扫描模式**下拉框有三个选项：

### 5.1 元素（Element）

最常用。扫描单个数值，支持多种比较条件。

### 5.2 数组（Array）

扫描"连续多个元素"，例如一次扫 5 个 `i32`、或者一段 `f32` 坐标。
选定数组模式后，数值框支持用逗号分隔多个值（例如 `100,200,300`）。

### 5.3 模式（Pattern）

按**十六进制字节 / 通配符**扫描原始字节，类似 Cheat Engine 的 Array of Bytes（AoB）扫描。

- 输入示例：`48 8B 05 ?? ?? ?? ?? 48 85 C0`
- `??` 表示任意字节（通配符）。
- 适合定位代码特征、结构体特征字节串。

### 5.4 比较条件（约束）

每一行是一个"扫描条件"，点 `+` 可以添加条件（最多 5 个），点 `-` 删除该行。

| 分类 | 条件 | 含义 |
| --- | --- | --- |
| 立即数 | 等于 / 不等于 | 与给定值比较 |
| 立即数 | 大于 / 小于 / 大于等于 / 小于等于 | 范围比较 |
| 相对 | 已变化 / 未变化 / 增大 / 减小 | 与上一次扫描相比 |
| 增量 | 增加 x / 减少 x | 与上一次扫描相比变化了指定量 |

> 说明：相对/增量类条件依赖上一次记录的数值，必要时先用 **采集数值** 刷新基准值。

### 5.5 显示格式

数值框右侧的小按钮可以在**十进制 / 十六进制 / 二进制 / 字符串**等格式之间切换，用于输入或查看不同进制的值。类型为浮点时还可使用十六进制显示其字节表示。

## 6. 扫描结果的常用操作

在结果列表或**详情查看器**中右键，常用菜单项：

| 菜单项 | 作用 |
| --- | --- |
| **添加到项目** | 把当前地址/值保存到项目 |
| **在内存查看器中打开** | 跳到该地址查看原始内存 |
| **在代码查看器中打开** | 跳到该地址查看反汇编 |
| **编辑选中的数值...** | 批量修改 |
| **从结果中删除所选内容** | 移除误报结果 |

结果列表底部有分页控件（第一页 / 上一页 / 下一页 / 最后一页），分页大小可在**设置 → 扫描 → 扫描结果 → 结果分页大小**中调整。

## 7. 内存查看器

**窗口 → 内存查看器** 打开，或从结果条目右键"在内存查看器中打开"。

功能：

- **跳转到地址**：顶部输入框输入地址（支持 `0x` 前缀、十进制、二进制、模块+偏移）后回车。
- **字节浏览**：十六进制视图 + ASCII 视图，支持滚轮翻页。
- **选中字节**：拖拽选择一段字节；选中后会显示选中范围的解读面板（十六进制/十进制/字符串等）。
- **编辑字节**：直接双击/输入并提交即可写入内存。
- **复制 / 粘贴**：`Ctrl+C` / `Ctrl+V`，右键菜单同样提供。
- **右键菜单**：添加所选内容到项目（可按数据类型创建条目）、复制、粘贴等。
- **分页**：底部提供第一页/上一页/下一页/最后一页按钮；分页来源（读取哪些内存区域）在**设置 → 扫描 → 扫描参数 → 分页来源**中设置。

> 模块名提示：地址栏下方会显示该地址所属模块，`(无模块)` 表示不属于任何模块（通常是堆或匿名内存）。

## 8. 代码查看器与指令修改

**窗口 → 代码查看器** 打开。

功能：

- **反汇编浏览**：上方显示目标架构（如 `x86 指令集`），中间是地址 / 字节 / 汇编指令三栏。
- **跳转到地址**：输入地址或符号后回车。
- **断点**：点击指令左侧区域切换断点，用于配合调试跟踪。
- **复制指令 / 复制字节**：右键菜单。
- **编辑指令**：右键 → **编辑指令**，或双击指令，在输入框中写新的汇编指令，然后提交。
- **粘贴指令 / 粘贴字节**：把复制的指令或字节写入当前位置。

### 8.1 指令写入的长度处理

修改指令时如果新指令长度与原指令不一致，程序会弹出确认：

| 情况 | 选项 | 含义 |
| --- | --- | --- |
| 新指令更短 | **填充 + 写入** | 用空操作（NOP）填充剩余字节 |
| 新指令更长 | **填充 + 覆盖** | 会覆盖后续指令的若干字节 |
| 跨指令边界 | 确认对话框 | 提示将覆盖后续指令，需谨慎 |

> 术语：**空操作代码**即 `NOP`（0x90），执行后什么都不做。

### 8.2 常见用法：让一段代码失效

1. 找到修改数值的指令（例如 `sub [rax+10], edx`）。
2. 右键 → **替换为空操作代码**，该指令会被 NOP 覆盖。
3. 需要还原时，右键 → **恢复原始代码**。

## 9. 指针扫描

直接扫描得到的地址通常是**动态地址**，重启程序后会变化。指针扫描用于找到"基址 + 多级偏移"的稳定指针链。

### 9.1 打开与参数

**窗口 → 指针扫描器**。工具栏参数：

| 参数 | 说明 |
| --- | --- |
| **目标地址** | 要解析的动态地址（可从项目浏览器自动填充） |
| **深度** | 指针层数，通常 3–5；越大越慢 |
| **偏移** | 每层允许的偏移范围（如 0 表示只找偏移为 0 的层） |
| **指针大小** | 目标进程的指针宽度（x64 通常 `u64` / 8） |
| **内存空间** | 在哪些内存区域里找（静态 / 堆 / 全部） |

### 9.2 流程

1. 先用普通扫描找到当前数值的地址，添加到项目。
2. 打开指针扫描器，填入目标地址（或从项目浏览器自动填充）。
3. 设置深度、偏移、指针大小，点击**开始扫描**。
4. 等待扫描完成，结果区显示候选指针链（列为：模块 / 偏移、数值、已解析、深度）。
5. **校验**：重启目标程序（让地址变化），再用**校验地址/校验数值**执行校验，只有依然能解析到正确地址的链才是有效的。
6. 选中合适的链 → **将选中的指针链保存到当前项目**。

> 提示：状态栏会显示扫描/校验进度与摘要（如"指针扫描完成 | …"）。若失败会提示"指针扫描启动失败，请查看日志。"

## 10. 调试跟踪（查找谁在读写）

**窗口 → 调试跟踪** 打开。

用途：找出"哪条指令在读/写了这个地址"，这是定位关键数据结构的核心手段。

### 流程

1. 在结果列表或项目条目上右键 → **查找写入此地址的位置**（或读取 / 访问）。
2. 程序提示需要附加调试器，确认后开始跟踪（"正在等待断点命中。"）。
3. 让目标程序触发一次该地址的读写（例如在游戏里执行相关操作）。
4. 跟踪窗口会列出命中的指令（地址、指令、访问类型、时间）。
5. 右键命中项 → **添加到项目**，把指令保存下来。
6. 可按需：
   - **暂停采集 / 继续采集**：控制是否继续记录。
   - **停止跟踪**：结束并解除调试器。
   - **替换为空操作代码 / 恢复原始代码**：直接修改命中的指令。

> 注意：部分程序有反调试保护，附加调试器可能导致目标崩溃或退出；请自行评估风险。

## 11. 详情查看器与结构编辑

**详情查看器**用于显示当前选中对象的"字段 → 数值"表格（相当于结构体查看器）。

- 每行是一个字段，显示字段名、类型、数值。
- 单击数值可直接编辑，回车提交。
- 数值框右侧按钮可切换**显示格式**（十进制 / 十六进制 / 二进制 / 地址等）。
- 对指针类型字段，可以编辑**指针偏移列表**。
- 顶部可切换**容器类型**（元素 / 数组）以及数据类型。
- 右侧的按钮可将该字段**在内存查看器中打开**或**在代码查看器中打开**。

典型用法：把一个扫描结果添加到项目后，在详情查看器中把它的类型从 `i32` 改成"指针 + 偏移"，从而直接读写多级指针指向的值。

## 12. 项目系统

项目用来持久化你的分析成果（地址、指针链、符号、布局等）。

### 12.1 创建 / 打开项目

- 菜单 **文件 → 选择项目**：打开项目选择器。
- 项目选择器工具栏：**刷新项目列表**、**浏览并打开项目文件夹**、**创建新项目**。
- 双击项目可编辑名称或删除（删除会提示"这将永久删除项目目录及其文件。"）。

### 12.2 项目根目录

默认保存在**当前用户的"文档"目录**下的 `Squalr` 文件夹，可在 `project_settings.json` 中修改 `projects_root`。
每个项目是磁盘上的一个目录，内部以 JSON 文件保存条目。

### 12.3 项目浏览器

- 工具栏：**添加新的项目条目**、**关闭此项目**、筛选框。
- 右键菜单：
  - **新建地址 / 新建文件夹**
  - **复制 / 剪切 / 粘贴 / 删除**
  - **在内存查看器中打开 / 在代码查看器中打开**
  - **编辑数值 / 编辑偏移**
  - **查找读取/写入/访问**
  - **提升为符号 / 剥离符号信息**
  - **替换为空操作代码 / 恢复原始代码**
  - **导出项目为表格...**（菜单：文件）

### 12.4 项目条目预览

项目浏览器下方会显示选中条目的实时预览值（例如地址当前的值），数据来源与刷新间隔可在设置里调整。

## 13. 符号树、符号布局与符号解析器

这一部分属于进阶功能，用于把"裸地址"变成"有名字、有结构"的语义对象。

### 13.1 符号树

**窗口 → 符号树**（需先打开项目）。

- 显示模块 → 符号 → 字段的树形结构。
- 右键菜单：**在内存查看器中打开 / 在代码查看器中打开 / 添加到项目 / 编辑符号布局... / 重命名 / 新建模块 / 删除**。
- 未打开项目时提示："打开一个项目以浏览符号树。"

### 13.2 符号布局编辑器

**窗口 → 符号布局**。用于定义结构体布局（字段名、偏移、数据类型、容器类型、变体等）。

- 支持固定数组 / 动态数组 / 指针数组等容器类型。
- 未分配的区间会以"未分配"行显示，可拆分、合并、定义字段。
- 打开项目后可编写可复用布局。

### 13.3 符号解析器

**窗口 → 符号解析器**。用于定义"自定义地址解析规则"（例如把某个符号表达式解析成实际地址）。

- 可创建 / 重命名 / 删除解析器。
- 支持多种运算符（等于、不等于、大于等于、小于等于等）。

> 这三者主要服务于大型逆向工程与自动化场景，新手可以先跳过。

## 18. 常见问题（FAQ）

### Q1：无法打开/读写目标进程

- 确认以**管理员身份**运行。
- 某些程序（带反作弊、受保护进程、系统进程）即使管理员也无法打开，这是操作系统与目标程序自身的保护，属于正常现象。
- 32 位 / 64 位差异：64 位 Squalr 可以操作 64 位与 32 位进程；部分受保护进程需要特殊手段。

### Q2：扫不到数值

1. 换数据类型：`i32` → `f32` → `i64` → `u16`/`u8`。
2. 数值可能是**加密或压缩存储**的（例如显示 1000，内存里是 100000 或其他变换）。可以尝试：
   - 扫描"未变化"逐步缩小范围（不依赖具体数值）；
   - 用"已变化/增大/减小"做变化型扫描；
   - 用十六进制模式扫描特征字节。
3. 数值可能显示为整数但实际是浮点。试试 `f32`。
4. 数值可能是"当前值 = 基础值 + 加成"的派生值，需要先找到基础值。
5. 调整"内存类型/分页来源"设置，扩大或缩小查询范围后重新扫描。

### Q3：重启游戏后地址失效

正常现象——动态地址。请使用**指针扫描**得到指针链，或把地址"提升为符号"。

### Q4：找不到自己想要的窗口/功能

菜单 **窗口** 里勾选对应窗口；如果窗口被关掉了，在这里重新打开。**布局 → 重置布局** 可恢复默认排布。

### Q5：界面显示成方块（□□□）

说明系统里找不到中文字体。解决办法：

1. 确认系统 `C:\Windows\Fonts` 下存在中文字体（`msyh.ttc`、`simhei.ttf`、`Deng.ttf` 等）。
2. 或手动放一个字体文件到 `squalr.exe` 同级的 `fonts` 文件夹（支持 `.ttf` / `.ttc` / `.otf`，例如 `NotoSansSC-VF.ttf`）。
3. 重启程序。

### Q6：扫描很慢 / 内存占用很高

- 缩小内存查询范围（设置 → 内存 → 虚拟内存查询）。
- 适当增大**扫描对齐**（对齐 4 或 8 会更省内存）。
- 避免同时保留过多扫描结果；及时删除误报。
- 确认没有勾选"执行额外的调试校验扫描"。

### Q7：输出窗口里全是英文日志

引擎内核与插件的日志保持英文输出（便于排查问题），界面与提示已全部汉化。出现问题时可以把日志内容附到反馈里。

### Q8：修改数值没反应 / 数值马上变回去

- 该地址可能只是显示缓存，真正的值在别处（继续缩小结果范围）。
- 目标程序每帧重算该值：需要修改**写入它的代码**（代码查看器 → 替换为空操作代码），或用**冻结**功能。
- 某些值在服务端校验，本地修改无用。

### Q9：怎么把分析结果分享给别人

菜单 **文件 → 导出项目为表格...**，会导出为 JSON 表格。

### Q10：程序打不开/闪退

1. 确认系统为 64 位 Windows 10/11。
2. 确认 exe 所在目录**可写**（否则配置写入失败）。
3. 尝试以管理员身份运行。
4. 若仍然闪退，请记录下操作步骤与输出窗口最后几条日志。

### Q11：程序会自己更新吗？怎么升到新版本

不会自动更新。本汉化版已**禁用应用内自动更新**：程序启动时不会联网检查版本，也不会下载并替换自身。原因是上游发布的更新包是英文版，保留自动更新会在上游发版时把中文界面覆盖掉。

需要新版本时，请前往本仓库的 **Releases** 页面手动下载，解压后覆盖旧目录即可。配置文件（`docking_settings.json` 等）位于程序目录内，项目文件默认在 `文档\Squalr\`，覆盖程序不会丢失它们。
